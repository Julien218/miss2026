# Sponsors 2026

`full-sprite.b64` contient la version WebP optimisée du sprite réalisé exclusivement à partir des 43 visuels officiels fournis par l'organisation.

Le script `../prepare-sponsors.mjs` vérifie sa taille et son SHA-256 avant chaque build, puis génère `client/public/sponsors/sponsors-2026-runtime.webp`.

Ne pas remplacer ce fichier par une capture ou une URL externe : les visuels doivent rester embarqués dans le build Railway.
